# E2 LAB – Purple Edition (privater Electribe-2-Nachbau)

Start: index.html im Browser (Chrome/Safari/Edge) öffnen. Auf dem Handy quer halten.

Bedienung
- Gate Arp: Melodie-Parts (Bass, Lead, Pluck, Pad, Perc) spielen jeden Step doppelt (Grundton + Quinte/Oktave).
- Pads: Trigger = Part wählen + spielen, Sequencer = Steps des gewählten Parts setzen, Keyboard/Chord = Töne spielen,
  Part Mute / Part Erase / Step Jump = jeweils pro Pad.
- Play/Stop/Rec/Tap, Leertaste = Play. Rec nimmt Pad-Treffer live in den Pattern auf.
- Drehregler: mit dem Finger/der Maus senkrecht ziehen. Lila Kugel = Tempo.
- Oscillator-Regler wählt den Klang des Parts (Kick, Snare, Hat, Bass, Lead, Pluck, Pad, Perc).
- Modulation-Regler = LFO-Form, Depth/Speed = LFO auf Filter. MFX Send = Part geht in den Tape Delay, XY-Pad steuert Zeit/Feedback.
- Pattern 1–4, Write speichert im Browser, < > = Tempo (Shift = ±10), Oktave +/− fürs Keyboard.
- Ohne Funktion: Touch Scale, Pattern Set, Input Level.

Hardtekk-Setup: Start bei 175 BPM, harter verzerrter Kick (Part 1), Offbeat-Bass (Part 4), Clap (Part 2), Offbeat-Hat (Part 3), Rave-Stab (Part 5). Tempo mit der lila Kugel oder < > (Shift = ±10) bis 240 BPM.

Neu: Distortion-Regler (oben, neben Input Level) verzerrt den ganzen Mix. Kick Roll (Taste unten links, früher Touch Scale): gedrückt halten, der Kick (Part 1) wird immer schneller. Part 4 ist jetzt ein Reverse Bass (Oscillator-Regler, Stellung REVBASS): der Bass schwillt an und wird vom nächsten Kick abgeschnitten.

Version Neon-Black: Gehäuse komplett schwarz mit Neonfarben. 17 Klänge pro Part (Oscillator-Regler): Kick, Snare, Hat, Bass, Lead, Pluck, Pad, Perc, Reverse Bass, Clap, Open Hat, Tom, Screech, Acid, FM-Bell, Supersaw, Sub. Parts 9-16 sind vorbelegt mit Clap, Open Hat, Tom, Screech, Acid, FM-Bell, Supersaw, Sub. MFX Send schickt einen Part zusätzlich in einen Hall.

Pattern 1-4 lassen sich gleichzeitig einschalten (übereinander spielen). Der weiß umrandete Pattern-Taster ist der, den du gerade bearbeitest (Sequencer, Rec, Part Erase). Mindestens ein Pattern bleibt immer an.

Meter (Taste links neben Gate Arp): blendet links neben dem Display einen Lautstärke-Balken ein (grün, gelb, rot, mit weißer Spitzenmarke).

Multi (kleine Taste zwischen Amp EG und IFX On): Multi aus = Pattern 1-4 schalten exklusiv (nur eins spielt). Multi an = mehrere Pattern-Tasten gleichzeitig aktiv, alle spielen übereinander.
